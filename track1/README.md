# Track 1 — Offline Multi-speaker ASR

## Submission

> **Required:** Upload a ZIP archive containing `hypothesis.seglst.json`.

ZIP root:

```text
hypothesis.seglst.json
```

### Result Format

Use UTF-8 and a MeetEval SegLST JSON array:

```json
[
  {
    "session_id": "session_001",
    "speaker": "speaker_0",
    "start_time": 0.5,
    "end_time": 1.2,
    "words": "你好"
  }
]
```

| Field          | Type   | Requirement                                                        |
| -------------- | ------ | ------------------------------------------------------------------ |
| `session_id` | string | ID from the evaluation manifest                                    |
| `speaker`    | string | Nonempty ID without whitespace; consistent within each session     |
| `start_time` | number | Segment start in seconds from recording start                      |
| `end_time`   | number | Segment end in seconds; `0 ≤ start_time < end_time ≤ duration` |
| `words`      | string | Recognized segment text                                            |

- Include every evaluation session, with no extra IDs.
- Order each session's segments by `start_time`.
- For a session with no recognized text, include one record with `speaker: "empty"`, `words: ""`, `start_time: 0` and `end_time: 0.0000625`.
- Timestamps describe acoustic positions, not inference completion times.
- Scoring uses the submitted five fields; custom token timestamps do not override the timing convention.

### Output Files

| File                       | Content                                         |
| -------------------------- | ----------------------------------------------- |
| `hypothesis.seglst.json` | Recognition results included in the ZIP archive |
| `scores.json`            | tcpCER, generated by the evaluator              |

## Evaluation Inputs

| File                       | Required content                                              | Source                |
| -------------------------- | ------------------------------------------------------------- | --------------------- |
| `sessions.csv`           | One row per session; unique `id` and `audio_duration_sec` | Data preparation      |
| `reference.seglst.json`  | Reference `session_id,speaker,start_time,end_time,words`    | Data preparation      |
| `hypothesis.seglst.json` | Predicted segments in the required format above               | Inference             |
| Scoring UEM, optional      | `session_id 1 start end`, one scoring region per line       | Scoring configuration |

Audio and transcript schemas: [shared data formats](../README.md#data-formats).

## Run Stages

Run from `robohead_baseline/track1` in the `robohead` environment. Override paths with command-line options.

| Stage | Operation                                                 |
| ----- | --------------------------------------------------------- |
| `0` | Divide released AEC Train into fixed train/val partitions |
| `1` | Prepare train: wpe_offline, wpe_online and GT-guided GSS  |
| `2` | Prepare val: wpe_offline + ODAS, then NeMo diarization    |
| `3` | Apply GSS to val using predicted RTTM                     |
| `4` | Export fine-tuning manifests                              |
| `5` | Fine-tune Qwen3-ASR and select by complete-val tcpCER     |
| `6` | Transcribe val predicted-GSS audio                        |
| `7` | Score saved predictions                                   |

```bash
cd robohead_baseline/track1
bash run_track1.sh --stage 0 --source-dir /path/to/RoboHEARD/train
bash run_track1.sh --stage 1 --stop-stage 4 --gpu-id 0
bash run_track1.sh --stage 5
bash run_track1.sh --stage 6 --stop-stage 7 --gpu-id 0
```

- `--stage N`: one stage; `--stop-stage M`: run through M.
- Defaults: `--split val`, `--data-dir ../data/track1`, `--frontend-dir exp/frontend`, `--exp-dir exp`.

Stages 6–7 call [robohead_evaluate_v1.sh](../robohead_evaluate_v1.sh), stages 0–1: ASR inference, then tcpCER scoring.

## Training and Validation

Input: six-channel 16 kHz PCM16 `Audio_AEC/Sxxx.wav` and `DOC_AEC/Sxxx.TextGrid`.

Stage 0: [partition and transcript cleaning](../README.md#data-preparation).

| Partition | ASR input                                                                 | Annotation use                        |
| --------- | ------------------------------------------------------------------------- | ------------------------------------- |
| train     | Raw channel 0, wpe_offline channel 0, wpe_online channel 0, GT-guided GSS | Training targets and GSS guidance     |
| val       | GSS guided by predicted RTTM                                              | Scoring and checkpoint selection only |

- Training windows: up to 20 s; overlapping speech uses GSS only.
- Val windows: predicted RTTM only; complete-val references are used for tcpCER.
- Entry: `local/finetune.py`; config: `conf/finetune.yaml`.
- Input: `train.jsonl`, `val.jsonl`, `val_reference.json`.
- Start: Qwen3-ASR-1.7B; best-val checkpoint: `exp/qwen3_asr/final/`.
- Checkpoints: `save_total_limit` controls retention; set `resume_from` and keep the same `output_dir` when resuming.

### Validation Results

Val sessions with predicted-GSS audio; tcpCER collar 5 s.

| --------------------- | --------------: | --------------: |

## Evaluation

**Metric: tcpCER, ascending.** MeetEval uses a 5-second collar and the shared [normalization and timing rules](../README.md#tcpcer).

After preparing GSS windows and weights, run inference and scoring directly:

```bash
bash ../robohead_evaluate_v1.sh \
  --track 1 \
  --stage 0 \
  --stop-stage 1 \
  --segments-json exp/frontend/val/segments.json \
  --asr-model exp/qwen3_asr/final
```

Score saved predictions without inference:

```bash
bash ../robohead_evaluate_v1.sh \
  --track 1 \
  --stage 1 \
  --manifest-csv ../data/track1/val/sessions.csv \
  --reference-json ../data/track1/val/reference.seglst.json \
  --hypothesis-json submission/hypothesis.seglst.json \
  --output-dir exp/score
```

Evaluate a ZIP archive or an extracted directory:

```bash
cd ../..
python -m robohead_baseline.utils.submission \
  1 \
  /path/to/results.zip \
  robohead_baseline/data/track1/val \
  robohead_baseline/track1/exp/score
```

Use `--score-der true` at stage 7 for optional DER at collars 0 and 0.25 s. DER is not the ranking metric.

## Reference Baseline

```text
Six-channel AEC audio → wpe_offline → ODAS → Nemotron SD → RTTM
Six-channel AEC audio + predicted RTTM → GPU GSS → fine-tuned Qwen3-ASR-1.7B
```

- SD calls NeMo `examples/speaker_tasks/diarization/neural_diarizer/e2e_diarize_speech.py`.
- Training starts from [Qwen3-ASR-1.7B](https://huggingface.co/Qwen/Qwen3-ASR-1.7B).
- Optional weights: [Qwen3-ASR-FT-robohead](https://huggingface.co/SMIIP-lab/Qwen3-ASR-FT-robohead).
- Stage 6 override: `--asr-model models/Qwen3-ASR-FT-robohead`; validation weights must exclude val training data.
- [Configuration](conf/model.yaml) · [Shared installation](../README.md#installation).
